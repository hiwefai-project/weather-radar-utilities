Here are the weather radar images for simulation.

For the December 23rd, 2025, Campania Region (Italy) use case, download weather radar data as follows:

```bash

wget https://data.meteo.uniparthenope.it/instruments/rdr0/20251223.tar.gz --no-check-certificate

tar -xzvf 20251223.tar.gz

rm 20251223.tar.gz
```

and configure the weather radar websocket server as a simulator.
